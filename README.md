# Lab Assessment 4 – Predictive Analytics and Business Insight Generation

## Task 1: Trend Analysis and Forecasting (Power BI)
- Import and analyse the Superstore dataset.
- Create Month and ProfitStatus columns.
- Develop KPI cards for total sales, total profit and number of orders.
- Analyse yearly and monthly sales trends.
- Apply a 12-month sales forecast with seasonality 12 and 95% confidence interval.

## Task 2: Decision Tree Classification (KNIME)
- Create ProfitStatus labels (Profit/Loss).
- Select relevant input columns.
- Split the dataset into 70% training and 30% testing data.
- Train a Decision Tree model.
- Generate predictions using the Decision Tree Predictor.
- Evaluate the model using a confusion matrix, accuracy, precision and recall.
- Identify two rules from the Decision Tree.

## Task 3: K-Means Clustering (KNIME)
- Summarise customer-level sales, profit, orders and average discount.
- Normalise the four numerical features.
- Apply K-Means clustering with four clusters.
- Denormalise the cluster results.
- Profile and describe each customer cluster.
- Assign a business name to each cluster.

## Task 4: Prediction Reports and Business Insights (Power BI)
- Import Predictions.csv and Customer_Clusters.csv.
- Create a Key Influencers visual.
- Create a Decomposition Tree.
- Create a 100% stacked column chart showing Loss by Discount.
- Create a Predicted vs Actual Matrix.
- Create a Customer Segment Performance table.
- Add Region and Category slicers.
- Include KPI cards and the sales forecast chart.
- Answer the three business scenarios using text boxes.

## Business Scenarios

1. **Stock Planning:** Which months of 2018 need the most stock?
2. **Discount Policy:** What would capping discounts at 20% mean for loss-making orders?
3. **Customer Strategy:** Which cluster should be rewarded and which should stop receiving high discounts?
